FitQuest
FitQuest is a comprehensive fitness tracking app built using Flutter. It empowers users to track their fitness progress and interact with other fitness enthusiasts through a built-in chat feature.
Features

Progress Tracking: Users can log and monitor their fitness activities, set goals, and track achievements over time.
Community Chat: A social feature that allows users to connect, share tips, and motivate each other.
User-Friendly Interface: Intuitive and responsive design to ensure a seamless experience.

Tech Stack

Frontend: Flutter
Backend: Node.js
Database: MongoDB
Chat Feature: Socket.io for real-time communication

Installation
Follow these steps to set up the project locally:

Clone the Repository:
git clone https://github.com/yourusername/fittest.git
cd fittest


Install Dependencies:
flutter pub get


Run the App:
flutter run



Usage

Open the app and create an account or log in.
Set your fitness goals and start tracking your progress.
Use the chat feature to connect with other users and share your fitness journey.
